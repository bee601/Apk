# Habit Flow

Habit Flow is a local-first Android habit tracker.

## Features
- Daily habit checklist with animated card entrance.
- Streak and completion summary.
- Add custom habits from the New habit action.
- Data stored locally in app preferences.
- Modern dark interface with `#FFB0F0` accent styling.
- No camera, overlay, usage-access, network, or financial permissions.

Build with Android Studio using a recent Android SDK. The project targets SDK 35 and Android 10+.
